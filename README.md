# Monday’s Robotics Universe

Personal project journal for robot learning, AI-generated worlds, OpenUSD, simulation, and Sim-to-Real.

## Local preview

Open `index.html` directly, or serve the folder with any static HTTP server.

## Content tracks

- NavBot and robot learning
- SimForge Agent and digital world building
- OpenUSD certification journey
- Omniverse, Isaac Sim, Isaac Lab, Newton, and MuJoCo
- Domain randomization and Sim-to-Real

## Deployment

The repository includes a GitHub Pages workflow that deploys the static site on pushes to `main`.
