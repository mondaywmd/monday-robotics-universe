# Monday’s Robotics Universe

Personal project journal for robot learning, AI-generated worlds, OpenUSD, simulation, and Sim-to-Real.

## Local preview

Open `index.html` directly, or serve the folder with any static HTTP server.

## Content tracks

- NavBot and robot learning
- SimForge Agent and digital world building
- OpenUSD certification journey
- Omniverse, Isaac Sim, Isaac Lab, Newton, and MuJoCo
- Domain randomization and Sim-to-Real

## Deployment

The repository includes a GitHub Pages workflow that deploys the static site on pushes to `main`.

## English and Chinese

English is the default at the original root URLs. Matching Chinese pages live in `zh/` with the same filenames and section IDs. Every header has explicit English / 中文 links; `language.js` preserves the current section when switching. There is no browser-language redirect or translation service dependency.

When adding or editing an article, update both language versions, preserve matching section IDs, and add reciprocal `hreflang` and canonical links. Chinese pages link to shared assets with `../assets/` and keep article navigation within `zh/`. Historical screenshots and original source documents remain in their recorded language; surrounding text explains the evidence in each language. The latest three trash-perception recordings and the PPO control diagram also have English editions.
