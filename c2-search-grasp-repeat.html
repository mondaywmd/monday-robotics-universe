2026.10.29 / C2 / YOLOE + MOBILE MANIPULATION

Search. Grasp. Repeat.

From color segmentation to YOLOE, then two consecutive search-and-grasp runs—including a cube placed behind the robot.

ObserveSearchLocateApproachGrasp

Too many red things at home.

The earlier version used red color segmentation to find the cube. In my living room, red patterns and other objects could also trigger a detection. I switched to YOLOE, the model I had already used in simulation, so target selection would no longer depend on color alone.

Search beyond the current camera view.

The new “Search and Grasp” button connects observation, search, localization, approach and grasping. If the cube is not visible, C2 rotates its base while running detection. Once a target is found, it stops, localizes again, approaches a parking point, restores the grasp pose, and takes a fresh close-range observation before grasping.

Search also uses live LiDAR data: when an obstacle blocks rotation, the implemented logic looks for a traversable nearby position, moves there and resumes searching. This is a local search-and-reposition workflow, not a claim of autonomous whole-home patrol.

Two runs, with the target moved behind the robot.

I ran the task twice in succession. After the first successful grasp, I placed the cube behind the robot, outside its current view, and clicked “Search and Grasp” again. It searched for the new position and successfully picked up the cube again.

Both runs succeeded. I was pleasantly surprised by how smoothly this step came together. These are two successful demonstrations, not a measured success rate across many environments.

What I want to test next.

Try more placements, lighting conditions and distracting objects, and observe how often detection, local navigation and grasping succeed together. The immediate milestone is a complete task started with one click, including searching for a target that is initially out of view.
