01 / IT’S A VIBE

记得两年前做 Stranger Things Season 5 的时候，项目组里突然开始流行一句话：“It’s a vibe.”

这句话像传染病一样在聊天频道里蔓延，大家纷纷开始用，还伴随着各种 meme 和表情。真的很好笑。Emma，you know I’m talking about you—you started this.

没想到两年后，我坐在这里，真的开始 vibe 起了这个网站，也 vibe 起了自己的小兴趣。只是这次，vibe 不再只是片场里的一个梗，而是一种新的工作方式：带着问题开始，用 AI Agent 快速搭建和实验，再回到画面、数据与物理行为中判断它到底有没有成立。

02 / PARALLEL WORLDS

越了解机器人世界，
越觉得它似曾相识。

2023 年的 ChatGPT moment 所产生的作用力，很快延展到了机器人、仿真和 Digital Twin。我并不是为了追逐热潮才来到这里；恰恰相反，是了解得越多，我越发现 VFX 与机器人像两个平行空间。

VFX / FILM创造可信的数字世界

真实感、物理模拟、程序化生成、复杂资产、镜头验证与 production pipeline。

ROBOTICS / SIMULATION创造可学习的数字世界

传感器、动力学、场景生成、资产语义、仿真验证、训练管线与 Sim-to-Real。

具体问题不同，但我们都在追求类似的东西：让复杂系统可组合、可重复、可扩展、可验证，并最终让一个数字世界对真实世界有用。

03 / DOMAIN KNOWLEDGE

VFX · Houdini · OpenUSD

我在 ILM 使用由 Pixar 发起并开源的 OpenUSD，也长期追求近乎极致的真实物理模拟与视觉呈现。对于一个做了十多年 Houdini TD 的人来说，proceduralism 不是一个新概念，而是一种 native 的思考方式。

01Proceduralism

不是手工摆出一个结果，而是定义能持续生成结果的规则。

02Simulation

尊重约束、尺度、动力学和失败，而不是只让画面“看起来会动”。

03OpenUSD

通过 Stage、Prim、Layer、Composition 和 Variant 组织复杂数字世界。

04Pipeline thinking

让资产、工具、版本、证据与上下游系统能够可靠地流动。

THE SHARED OPERATING SYSTEM

两个领域真正共通的，
是一套解决问题的方法。

在高强度、强 deadline 的 production 环境里，我每天面对的并不是一道有标准答案的题，而是一连串需要快速判断、拆解、验证和沟通的问题。这套能力同样适用于机器人训练。

01 · FRAME重新定义问题

把模糊反馈拆成核心约束、可控变量和可验收结果；先问问题是否定义正确，再决定方法。

→
02 · ITERATE调整参数与策略

版本迭代不只是改数值；有时要换方法、改变策略，甚至推倒原来的假设重新开始。

→
03 · VERIFYDebug 与迅速验证

用最小实验隔离问题，先做 smoke test，再扩大规模；让画面、日志和数据共同回答“改动是否真的有效”。

→
04 · ALIGN沟通并继续迭代

与下游、总监和客户对齐目标与限制，把反馈翻译成下一版可执行的技术决策。

快速学习、抓住核心问题、在压力中保持判断力，以及对新技术的 adaptation，并不是从 VFX 跳到 Robotics 后才重新获得的能力——它们正是两个领域共享的底层能力。
